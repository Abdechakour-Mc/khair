# 05: Admin sees who signed up

**What to build:** The Admin opens a Task and sees every Volunteer who claimed
a Slot, with the name they gave and a phone number they can tap to open
WhatsApp or place a call.

That tappable number is deliberately the whole reminder system. A nudge the day
before prevents the no-show that a reliability record merely documents, and it
costs no provider, no message fees and no scheduled delivery to debug.

**Blocked by:** 02, 04.

**Status:** ready-for-agent

- [ ] A Task's Admin page lists every live Signup with the name snapshot taken
      when it was made
- [ ] Each Volunteer's phone number is tappable, opening WhatsApp or a phone
      call on a mobile device
- [ ] The list shows how many Slots are claimed against how many are needed
- [ ] A Task with no Signups yet shows a composed empty state saying so, not a
      blank area
- [ ] Signup details are reachable only with a valid Admin session
- [ ] No Volunteer name or phone number appears anywhere on the public pages
- [ ] The page is usable on a phone, where the Admin will actually read it
